Settings

This scratchpad is stored in the Jnrobox/scrpad GitHub repository. To save and sync across devices, paste a fine-grained GitHub Personal Access Token with Contents: Read & Write permission for that repository.

  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens
  2. Create a token scoped to Jnrobox/scrpad with Contents: Read and Write
  3. Paste it below

The token is stored only in this browser's localStorage and is sent only to api.github.com.
