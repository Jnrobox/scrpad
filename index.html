The note is stored in the Jnrobox/scrpad GitHub repository. To save and sync across devices, paste a fine-grained GitHub Personal Access Token with Contents: Read & Write permission for that repository.

  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens
  2. Create a token scoped to Jnrobox/scrpad with Contents: Read and Write
  3. Paste it below

The note is stored as a JSON node in a Firebase Realtime Database. Paste the note URL below — its secret path is the only credential needed (Firebase console → Realtime Database → Data → the node URL).

Settings are stored only in this browser's localStorage. Use the same backend on every device to see the same note.
